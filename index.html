From an address to a living thing

Nothing is stored and nothing is random. Hash the address, read the hash as genes, and the same creature grows every time, on any computer.

It prints itself

A quine is a program whose output is its own full source. Run any glyphling in a clean interpreter with no globals and a 64-step limit, then compare the two.

Every 5M you hold is one glyphling

Glyphling #1 is your address and #2 is address:2, and so on up. Buy past the next 5M and another is born. Drop below it and the newest one returns to the code. With 1B tokens in total, there can never be more than 200.

Balances load from the chain once the $GLYPH contract is live. Until then, type an amount.

Two glyphlings make a kid

A kid takes gene A from one parent and gene B from the other, so two species can make a hybrid. It counts toward both parents' families while it lives.

    Every hour, every copy is checked

    On the hour each glyphling runs and copies itself. A copy only counts if it hashes to the same sha256. Your browser re-runs that check for the whole colony.
